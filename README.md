# 🎂 生日提醒（BirthdayReminder）

面向 [ClassIsland](https://classisland.tech) 2.x 的生日提醒插件。从 Excel 导入姓名与生日，自动计算年龄与倒计时，并在生日临近/当天通过**桌面弹窗**、**ClassIsland 横幅**、**全屏强调动画**、**语音播报**四种方式提醒你，再也不会忘记身边人的生日。

## ✨ 功能一览

- 📊 **Excel 导入 / 导出**：姓名、生日两列即可，支持批量导入，支持“仅月日”（未知出生年份）。
- 🔁 **多种提醒时机，可同时设置多个**：当天、提前 1 / 3 / 7 / 30 天，也可以自定义天数，每个人都可以单独配置。
- 🗓 **每年自动提醒**：只需要维护一次生日数据，插件会按公历自动计算下一年的生日，无需每年重新设置。
- 🈲 **不支持农历**：只处理公历（阳历）生日。
- 🧩 **多条提醒自动合并成一条**：同一时间点如果有多人满足提醒条件，会合并为一条消息，不会刷屏。
- 🔔 **桌面弹窗**：独立于 ClassIsland 的自定义弹窗，在屏幕右下角显示。
- 📣 **ClassIsland 横幅提醒**：使用 ClassIsland 内置提醒系统展示。
- 🎇 **全屏强调动画**：重要生日不会被错过。
- 🗣 **语音播报**：自动朗读提醒内容。
- 🎉 **生日当天播放特殊动画**：当天的提醒会更醒目。
- 🎂 **自动计算年龄**：在提醒文本中显示“即将年满 XX 岁”。
- 🚫 **防止重复提醒**：同一天同一条规则只会提醒一次。
- 🔍 **搜索 / 分类 / 排序**：快速在名单中查找、按分类筛选、按生日/年龄/姓名排序。
- 💾 **备份与还原**：一键创建备份压缩包，可随时还原或迁移到其它电脑。
- 🧪 **测试效果**：设置页面内置测试按钮，可以立即预览四种提醒效果。
- 📈 **总览看板**：下一个生日是谁、距离最近生日还有几天、本月生日列表、今日寿星，一目了然。
- 🧱 **方便拓展**：数据、计算、提醒渠道分层解耦，方便二次开发（详见下方“代码结构”）。

## 📥 Excel 格式

| 姓名 | 出生日期 | 分类 | 备注 | 提醒时机(天,逗号分隔,0=当天) | 是否启用(是/否) |
| --- | --- | --- | --- | --- | --- |
| 张三 | 1990-05-20 | 朋友 | 示例 | 0,1,3,7 | 是 |
| 李四 | --12-01 | 同事 | 未知出生年份示例 | 0,3 | 是 |

在设置页面的“导入 / 导出 / 备份”区域点击“下载导入模板”即可获得一份带说明的模板文件。

## 🧭 使用方法

1. 安装插件后，打开 ClassIsland【应用设置】→【插件】→【生日提醒】，进入插件设置页面。
2. 在“生日名单管理”中点击“新增”手动添加，或在“导入 / 导出 / 备份”中导入 Excel 文件。
3. 在“提醒方式”中按需开启桌面弹窗 / 横幅 / 全屏强调动画 / 语音播报，并可以点击“测试效果”按钮立即预览。
4. 在“提醒文案模板”中自定义提醒文案，支持 `{name}` `{age}` `{ageText}` `{category}` `{days}` `{date}` 占位符。
5. 完成设置后插件会自动在后台定期检查，无需其它操作。

## 🧱 代码结构（方便拓展）

```
BirthdayReminder/
├─ Models/                 数据模型（人员、全局设置、提醒日志）
├─ Services/
│  ├─ BirthdayCalculatorService.cs   纯逻辑：年龄/倒计时/下一个生日计算
│  ├─ BirthdayStorageService.cs      数据持久化、搜索筛选排序、导入导出、备份还原
│  ├─ BirthdayReminderEngine.cs      定时检查 + 合并 + 去重 + 分发四种提醒渠道
│  ├─ DesktopPopupService.cs         桌面弹窗管理
│  └─ NotificationProviders/         ClassIsland 提醒提供方
├─ Views/                  设置页面、添加/编辑窗口、桌面弹窗窗口
└─ Helpers/                Excel 读写、文案模板占位符替换
```

如果你想继续扩展，比如：

- 想让生日信息显示在主界面组件（跑马灯）上：新增一个继承 `ClassIsland.Core.Abstractions.Controls.ComponentBase` 的组件，并在 `Plugin.cs` 中调用 `services.AddComponent<T>()` 注册即可，数据可以直接复用 `BirthdayCalculatorService` 与 `BirthdayStorageService`。
- 想接入微信 / 邮件等外部提醒渠道：在 `BirthdayReminderEngine.Dispatch` 方法中按开关追加你自己的发送逻辑即可。
- 想支持农历：可以在 `BirthdayPerson` 中增加“历法”字段，并在 `BirthdayCalculatorService` 中引入农历转换库（如 `LunarCalendar`）扩展计算逻辑。

## ⚠️ 注意事项

- 本插件只支持公历（阳历）生日，不支持农历。
- 请不要手动修改插件配置目录下的 JSON 文件，建议通过设置页面操作，避免格式错误导致加载失败（若真的加载失败，插件会自动使用备份或默认值，不会导致 ClassIsland 崩溃）。
- 桌面弹窗依赖桌面会话，纯服务器/无图形界面环境下可能无法显示，不影响其它提醒渠道。
